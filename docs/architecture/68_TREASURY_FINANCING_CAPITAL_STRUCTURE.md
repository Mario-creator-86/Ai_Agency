# Treasury, Financing & Capital Structure

## Purpose

Allow the CEO to manage liquidity realistically without giving the system access to real banking/credit transactions.

## Funding sources

### Operating revenue
Settled channel/social/sponsor/donation/etc. receipts.

### Owner capital contribution
Owner confirms an external injection. VR ledger credits cash/equity.

### Owner loan
Owner confirms or authorizes a virtual shareholder-style loan with interest.

### Virtual external financing
A simulated facility whose terms are benchmarked to current real-market comparables.

## Financing workflow

1. CEO identifies funding need and purpose.
2. Finance calculates amount/runway gap.
3. Treasury searches current comparable market terms.
4. References are stored with source/date/context.
5. Finance computes debt capacity.
6. Legal reviews wording/constraints.
7. Governance/Owner approval if required.
8. Virtual FinancingAgreement is posted.
9. VR$ principal is credited.
10. Interest and repayment obligations become real constraints in the virtual ledger.

## Debt capacity

Do not allow unlimited debt.
Potential configurable metrics:
- trailing settled revenue;
- gross margin;
- runway;
- debt service coverage ratio;
- debt/revenue ratio;
- revenue volatility;
- concentration by platform;
- forecast confidence;
- outstanding debt;
- Owner guarantee flag.

A pre-revenue studio should generally have little/no third-party-style debt capacity unless Owner-backed.

## Market terms

The system must research current real-world comparable rates/terms at proposal time.

Store:
- reference source;
- date;
- currency;
- borrower type/comparable;
- indicative rate/range;
- fees if known;
- tenor;
- fixed/variable;
- notes.

Never present a public web reference as an actual offer to this studio.

## Interest

Support:
- fixed rate;
- variable/reference rate if implementable;
- simple amortizing schedule;
- bullet maturity;
- grace period if configured.

Interest accrual is deterministic and restart-safe.

## Stress / default

If the studio cannot meet scheduled virtual debt service:
- mark AT_RISK;
- Finance creates remediation plan;
- CEO may cut spend, seek Owner funding, restructure;
- default/restructuring can become a world/story event.

## No real loan execution

There is no tool for:
- loan application submission;
- signing credit agreement;
- accepting terms;
- transferring real funds.

Any future real financing remains a human Owner action outside the autonomous studio.
