# Content Quality, Analytics and Director Objectives

## Multi-objective scorecard

The studio should optimize a vector, not one number.

Potential dimensions:
- factual correctness;
- rights/policy;
- audience retention;
- completion;
- subscriber conversion;
- engagement;
- novelty;
- production cost;
- production time;
- failure rate;
- brand fit.

## Hard constraints

A content item cannot trade factual/rights failure for more predicted views.

## Analytics latency

Metrics arrive at different times.

Store observation windows such as:
- 1h;
- 24h;
- 7d;
- 28d.

Do not compare a 1-hour-old Short with a 30-day-old Short as if mature data were equal.

## Cohorts

Analyze by:
- topic;
- hook;
- duration;
- channel;
- visual format;
- voice;
- publish window;
- generation method.

## Causality caution

Correlation is not proof.

Director recommendations should distinguish:
- observed correlation;
- controlled experiment;
- plausible hypothesis.

## Quality floors

Set minimum quality thresholds independent of growth.

Example:
- factual gate pass;
- rights gate pass;
- technical QC pass;
- novelty above floor.

## Strategy updates

Use bounded weight changes and cooldown.

Do not let one viral outlier completely rewrite strategy.

## Revenue

Keep separate:
- views;
- estimated revenue;
- confirmed platform revenue;
- sponsorship;
- spendable/restricted VR$ treasury.

Only confirmed/appropriately sourced data should be labeled actual revenue.


## V4 Marketing / audience objectives

Marketing optimization should consider:
- episode conversion;
- returning viewers;
- qualified watch time;
- follower growth;
- community engagement;
- teaser payoff;
- audience fatigue.

Do not optimize CTR alone.

High click-through + poor retention/misleading comments is a negative signal.

Market Intelligence can segment observations by:
- platform;
- geography;
- language;
- topic;
- hook;
with adequate sample/confidence.


# V5 Financial objectives

Add business objectives, always subordinate to factual/legal/reliability hard gates:
- positive VR$ runway;
- sustainable content unit economics;
- provider cost efficiency;
- revenue diversification;
- healthy debt service capacity;
- controlled office/marketing discretionary spend;
- forecast calibration.

CEO should not maximize views while ignoring solvency.
