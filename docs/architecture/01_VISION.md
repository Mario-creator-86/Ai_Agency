# Product Vision v3

## North Star

Create a real autonomous digital media company that users can both **operate** and **watch**.

The company is represented as a top-down 2D office populated by AI employees. Their visible movements, operational conversations, tasks, errors and decisions are projections of real backend state.

## The product is not a fake simulation

The office must never become a decorative layer that pretends agents are working.

If the backend is idle, the office is idle.

If an external API is blocked, the employee appears blocked.

If the Director only proposed a hire but it was not approved/executed, the new employee does not appear.

## Core loop

Real work
→ content
→ real performance
→ learning
→ Director decisions
→ workforce/provider/strategy adaptation
→ better real work.

Real daily work also creates a second asset:

real events
→ Daily Studio Log
→ Showrunner
→ episodic office serial
→ audience attachment to characters/universe.

## Two outputs

### Channel A
International factual Shorts.

### Channel B
Serialized office workplace show based on actual prior-day operations.

## Dynamic universe

The cast evolves with the real workforce.

The office can evolve with the real world-state.

Future internal economy, fans, voting and room upgrades may influence the universe, but only through backend transactions.

## Long-term vision

The studio becomes:
- an autonomous content business;
- a software product;
- an observable AI organization;
- an entertainment/IP universe;
- a future interactive community platform.

## Success is not merely views

Product success includes:
- reliable unattended operation;
- factual quality;
- low human intervention;
- transparent agent behavior;
- controlled costs;
- reproducibility;
- channel growth;
- character/brand continuity;
- transferability of the business.

## v3 product principles

### Observable, not theatrical
The office is valuable because it makes real autonomy legible. Entertainment must never corrupt operational truth.

### Autonomy with graceful degradation
The product should keep doing useful work when one provider fails, but it should prefer honest blocking over low-quality fabricated completion.

### Constraint-first optimization
Accuracy, rights, policy, security and Owner limits are hard constraints. Growth is optimized inside those constraints.

### Dynamic but coherent company
The organization may evolve, but staff, roles, office changes and story canon remain historically consistent.

### Software plus media IP
The application, channels, characters, visual universe, production data and operational know-how are separate assets that should remain transferable.

## Success metrics by layer

**System**
- successful unattended runs;
- no duplicate side effects;
- recovery time;
- cost predictability.

**Content**
- factual pass rate;
- QC pass rate;
- novelty;
- production cost/time.

**Audience**
- retention;
- completion;
- repeat viewers;
- subscriber conversion;
- engagement.

**Organization**
- agent reliability;
- role specialization value;
- Director decision quality;
- provider resilience.

**Business**
- revenue/profit when available;
- low Owner intervention;
- IP cleanliness;
- transfer readiness.


## V4 — Company-as-a-living-organization

The long-term vision is broader than a content pipeline.

The studio should be able to evolve into a recognizable autonomous company with:
- departments;
- managers;
- specialists;
- culture;
- personalities;
- marketing;
- finance;
- legal/compliance;
- market intelligence;
- company events;
- public community.

The organizational structure should emerge from real needs rather than a permanently hardcoded org chart.

The media flywheel becomes:

**Operate → Create → Tell the story → Promote → Engage → Learn → Reorganize → Improve.**
